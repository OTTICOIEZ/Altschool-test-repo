# Git Repo Practice for Assessment

A minimal repository created for practicing Git workflows, command-line operations, and version control concepts for an upcoming assessment.

## Prerequisites

- Git installed locally
- Terminal / Bash environment

## Quick Start

```bash
# Clone the repository
git clone https://github.com/username/git-repo-practice.git

# Navigate into the project directory
cd git-repo-practice

# Check repository status
git status

# Create and switch to a new branch
git checkout -b feature-branch

# Stage and commit your changes
git add .
git commit -m "Add practice changes"

# Push branch to remote
git push origin feature-branch
```
